# CodeGuardian AI

AI-Powered Autonomous Code Intelligence Platform

> Analyze • Predict • Explain • Repair • Verify

---

## Vision

CodeGuardian AI is a production-grade AI platform that analyzes GitHub repositories using static analysis, Graph Neural Networks (GNNs), and autonomous AI agents to detect potential bugs, explain risks, generate fixes, and validate them in a secure execution environment.

This project is designed as a long-term AI Engineering portfolio project combining:

- Graph Neural Networks
- AI Agents
- Static Code Analysis
- Explainable AI
- FastAPI
- React
- Docker
- PyTorch
