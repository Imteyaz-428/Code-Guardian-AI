# Existing Systems and Differentiation

## Existing systems

AI coding agents such as Codex, GitHub Copilot coding workflows, Claude Code, and similar tools already provide repository understanding, code generation, refactoring, debugging, testing, review, and agentic execution.

Static-analysis/SAST platforms already provide rule-based bug and security detection, quality checks, and code metrics.

## What is NOT unique

Code Guardian must not claim these as unique:

- AI code generation
- repository-level context
- automated code review
- automated bug fixing
- test execution
- security scanning
- complexity metrics

## Proposed differentiation

Code Guardian focuses on a unified **Code Risk Intelligence + Verification** loop:

**Understand → Measure → Predict → Explain → Repair → Verify → Re-analyze**

Key directions:

1. Function/component risk ranking
2. Structural explanation of risk
3. Change-impact analysis
4. Graph-based ML/GNN research
5. Risk-aware repair
6. Verified patch outcomes

## Positioning

> Code Guardian AI is a code-risk intelligence and autonomous verification platform, not primarily a code-generation assistant.
